-Alkalmazott Technológiák
Az alkalmazás az alábbi technológiák és megoldások használatával készült:
* HTML5 / CSS3: A frontend felületek és a navigáció kialakításához.
* Natív JavaScript (ES6+): Memória alapú CRUD műveletek (JavaScript menü).
* React (Babel/Standalone): Komponensek és `useState` alapú adatkezelés (React menü, SPA).
* Fetch API: Kliens oldali kommunikáció a szerverrel natív módon.
* Axios: Szerverkommunikáció React környezetből.
* PHP: Backend API végpontok az adatbázis műveletekhez.
* MySQL: A labdarúgók, klubok és posztok adatainak tárolása.
* OOJS: Tiszta objektumorientált JavaScript osztályokkal és öröklődéssel (OOJS menü).

-Menüpontok és Funkciók
1. Főoldal: Az alkalmazás bemutatása.
2. JavaScript menü: CRUD műveletek JS tömbbel.
3. React menü: CRUD műveletek React State-tel.
4. SPA menü: Két egyoldalas React alkalmazás (Amőba és Számológép). (A kódok a `react/src` mappában találhatóak).
5. Fetch API menü: Adatbázis módosítása natív Fetch hívásokkal.
6. Axios menü: Adatbázis módosítása React és Axios segítségével.
7. OOJS menü: Grafikus pálya-szimulátor játékosokkal és labdákkal.
